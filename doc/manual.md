# Manual

**Installationsanleitung:** 


- **Dateien vorbereiten:** Gehe zuerst in den Ordner **`src`** und lade die Dateien `SplitSecond.ino` und `Webseite.html` herunter.

- **Arduino programmieren:** Öffne die Datei `SplitSecond.ino` in der **Arduino IDE**. Verbinde deinen physischen Arduino mit dem Computer und lade den Code auf das Board hoch.

- **Hardware aufbauen:**
  
  - Stecke den **ersten Taster (inkl. LED)** an den Pin **D5** an.
  
  - Stecke den **zweiten Taster (inkl. LED)** an den Pin **D7** an.

- **Webseite starten:** Öffne die heruntergeladene Datei `Webseite.html` im Browser (empfohlen wird **Google Chrome**).

- **Verbindung herstellen:** Klicke auf der Webseite auf die blaue Taste **"🔌 Arduino verbinden"**. Wähle in dem Fenster, das sich öffnet, deinen Arduino aus und bestätige die Verbindung.
